# Foro Regional TAC-IA - Proyecto Web

## Descripción
Sitio web del Foro Regional "Tecnologías del Aprendizaje con Inteligencia Artificial" organizado por UJAT/DACyTI. Evento virtual sincrónico, 28-29 de octubre de 2025.

## Paleta de Colores
- Rosa/Fucsia: #ff2b4f (primary)
- Rojo oscuro: #bd243e (secondary)
- Crema: #fefcf6 (background)
- CSS vars: --primary: 350 100% 58%, --secondary: 348 69% 44%

## Tipografía
- Display: Plus Jakarta Sans
- Body: Inter
- Mono: JetBrains Mono

## Estructura de Páginas
- `/` - Homepage con hero, about, ejes temáticos, programa, ponentes, noticias, CTA
- `/registro` - Formulario de registro de participantes
- `/ponencias` - Formulario de envío de ponencias con upload PDF
- `/noticias` - Lista de noticias/actualizaciones
- `/contacto` - Formulario de contacto + info
- `/admin/login` - Login admin
- `/admin` - Dashboard admin (CRUD noticias, ver registros/ponencias/contactos)

## Base de Datos (Prisma)
- User (admin auth)
- Participant (registros al foro)
- Submission (ponencias con archivo en S3)
- ContactMessage (mensajes de contacto)
- News (noticias/actualizaciones)

## Funcionalidades
- Auth: NextAuth con credenciales, admin panel protegido
- File upload: S3 presigned URLs para PDFs de ponencias
- Email: 3 notificaciones configuradas (registro, ponencia, contacto) → evento@evento.com / contacto@evento.com
- SEO: OG image, favicon, robots.ts, sitemap.ts

## Ejes Temáticos
1. Analíticas del aprendizaje desde perspectivas críticas y plurales
2. Entornos educativos inteligentes con enfoque decolonial e inclusivo
3. Innovación pedagógica con IA y voces emergentes
